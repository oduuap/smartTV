1. Application Overview

Description

Sports TV is a live sports streaming application designed for LG webOS Smart TVs. The app provides users with access to live football matches, real-time scores, and HD streaming with HLS support. It features an intuitive interface optimized for TV remote control navigation.

Live Sports Streaming HD Quality (HLS) Remote Control Navigation Real-time Scores Match Details Vietnamese Interface

Target Users

  • Primary: Vietnamese football fans who want to watch live matches on their Smart TV
  • Secondary: Sports enthusiasts looking for convenient streaming options
  • Age Group: 18-65 years old
  • Technical Level: Basic to intermediate TV users

Screen Purpose Key Elements

3. User Scenarios

Scenario 1: First Time User - Launching App and Finding a Match

User Profile: Nam, 35 years old, football fan, wants to watch a live match

Goal: Launch app and watch a live football match

Context: Evening, sitting on couch with TV remote

1

Launch Application

Action: User selects "Sports TV" from LG webOS launcher

System Response: App displays loading screen with "SPORTS TV LUONG SON" title and loading animation

Duration: 1 second

[Screenshot: Loading Screen with app logo and loading dots]
2

View Main Menu

Action: Loading completes automatically

System Response: Main menu appears with 4 category options displayed in a grid:

  • 1. Thể Thao (Sports) - focused by default
  • 2. Phim (Movies)
  • 3. Tin Tức (News)
  • 4. Âm Nhạc (Music)

Visual Feedback: First item (Sports) is highlighted with focus effect

[Screenshot: Main Menu with 4 category cards, Sports category highlighted]
3

Select Sports Category

Action: User presses ENTER/OK button on "Thể Thao" (already focused)

System Response:

  • Screen transitions to Sports List screen
  • Loading indicator appears: "Đang tải trận đấu..."
  • App fetches live match data from API

[Screenshot: Sports List screen with loading indicator]
4

Browse Live Matches

System Response: Match list displays in 3-column grid. Each match card shows:

  • Team logos (home vs away)
  • Team names
  • Current score
  • League name with colored badge
  • Commentator name and avatar
  • Live status indicator (if live)
  • View count

Action: User navigates using arrow keys (UP/DOWN/LEFT/RIGHT) to browse matches

Visual Feedback: Selected match card is highlighted with border and scale effect

[Screenshot: Sports List with multiple match cards in grid layout, one card focused]
5

Select a Match

Action: User presses ENTER/OK on desired match

System Response:

  • App calls match detail API to get video stream URL
  • Loading indicator appears
  • If successful, transitions to Video Player screen

Error Handling: If no video link found, shows error alert: "Không tìm thấy link video cho trận đấu này!"

6

Watch Match

System Response: Video Player screen displays:

  • Full-screen video player with HLS stream
  • Video automatically starts playing
  • Match title displayed at top
  • Commentator information shown
  • Back button in top-left corner

User Controls:

  • PLAY/PAUSE - control playback
  • BACK button - return to match list
  • Remote media keys supported

[Screenshot: Video Player with live match, showing match info overlay]

Outcome: User successfully finds and watches a live football match in under 30 seconds from app launch

Scenario 2: Returning User - Resume Previous Match

User Profile: Hoa, 28 years old, was watching a match but had to leave

Goal: Continue watching from where she left off

Context: Previously closed app while watching, now returning

1

Launch App

System Response:

  • App detects saved state in localStorage
  • Automatically restores previous screen (Video Player)
  • Loads the same match that was playing

2

Resume Playback

System Response:

  • Video player loads
  • After 3 seconds, automatically seeks to saved position
  • Shows notification: "⏩ Tiếp tục từ MM:SS"
  • Notification fades after 3 seconds

Outcome: User seamlessly continues watching without having to navigate or search again

Scenario 3: User Exits App

User Profile: Any user finishing their session

Goal: Close the app

1

Press Back/Exit Button

Action: User presses BACK button on remote when on Main Menu

System Response: Exit confirmation dialog appears with:

  • Title: "Thoát ứng dụng?"
  • Message: "Bạn có chắc muốn thoát Sports TV không?"
  • Two buttons: "Có" (Yes - focused) and "Không" (No)

2

Confirm or Cancel

If "Có" (Yes): App closes and returns to LG webOS launcher

If "Không" (No): Dialog closes, user stays in app

4. User Flow Diagram

    [App Launch]
         ↓
    [Loading Screen] (1 sec)
         ↓
    [Main Menu]
         ↓ (Select "Thể Thao")
    [Sports List Screen]
         ↓ (Loading matches from API)
    [Display Match Cards]
         ↓ (User selects match)
    [Load Match Detail API]
         ↓
    [Video Player Screen]
         ↓ (Video plays)
    [User watches match]
         ↓
    [Back to Sports List] ← → [Back to Main Menu] ← → [Exit App]

Alternative Flows

  • No Internet Connection: Show error message, load fallback match data
  • Video URL Not Available: Show alert, stay on Sports List screen
  • API Timeout: Display fallback loading message
  • State Restoration: App reopens directly to last viewed screen

6. Error Handling & Edge Cases

Scenario User Experience System Behavior
No Internet Connection Loading indicator shows, then error message Fall back to cached/demo data if available
Video Stream Unavailable Alert dialog: "Không tìm thấy link video..." Stay on Sports List, allow user to try another match
API Timeout Extended loading state, then fallback data Show demo matches or cached matches
Video Playback Error Video player shows error message Log error, allow user to go back and retry
Empty Match List Message: "Đang tải trận đấu..." Show placeholder content
